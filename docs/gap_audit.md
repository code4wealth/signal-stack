## Priority closure plan
1. **(1) P0/P1 items**: Research missing profile fields + UI profile editor; Analysis `Opportunity / Threat / Neutral / Uncertain` + structured Brief opportunities/risks; Source metadata (`source_type`, `description`, `update_frequency`); Internal intelligence document-type selector + extracted insights; Context change old-vs-new comparison summary; `config.py` empty `DATABASE_URL` fix + `audit.py` tests.
2. **(2) Dedicated views**: Competitors tab (5–10 researched profiles), Duplicates view, Crawl errors view, Source history.
3. **(3) Intelligence feed filters**: Category, competitor/source, date, relevance, impact, verification, priority, classification.
4. **(4) Related-record linking**: Cross-source corroboration / shared-signal links across records.
5. **(5) Overview dashboard completeness**: Sources by category, record counts, latest crawl, latest report, scheduled job status.
6. **(6) PDF/XLSX upload**: Only if items 1–5 are complete and tested.
